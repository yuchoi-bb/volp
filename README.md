# 볼프 (Volp)

여행 경비를 미리 예측하고, 실제로 쓴 돈을 기록하는 안드로이드 앱.

## 무엇을 하는 앱인가

**경비**
- 목적지·기간·인원·여행 스타일로 **항목별 예상 경비**를 계산한다.
- 실제 지출을 입력하고 **예측 대비 실제**를 항목별로 비교한다. 하루 평균, 남은 예산,
  지금 속도로 갔을 때의 예상 최종 지출까지 함께 본다.
- 카드사 결제 문자와 알림을 읽어 **지출을 자동으로 모은다**(삼성·신한·하나, 국내/해외).
  여행 기간과 항목이 확실하면 확인 없이 바로 기록하고, 아니면 미확인함에 쌓는다.
- 해외 결제는 **현지 통화가 원본**이다. 환율은 하루 한 번 갱신하고 건별로 남긴다.
  명세서가 나오면 **실제 청구액에 맞춰 보정**한다.
- **통계**: 일자별 막대그래프, 항목별 비중, 통화별 합계. 여행 **리포트**로 공유.
- **지난 여행 경비**: 다녀온 여행의 실제 지출을 모아 하루 얼마·한 사람 하루 얼마를 낸다.
  그 값으로 다음 여행 **예측을 내 씀씀이에 맞춰 고쳐 잡는다**.

**여행**
- 일자별 **일정과 동선**. 장소마다 거리에 맞는 이동수단과 예상 시간·요금을 붙인다.
- 현재 위치를 알면 **다음 일정까지 얼마나 걸리는지** 알려 주고 지도 앱으로 넘긴다.
- **날씨 예보**에 맞춰 **챙길 것**을 뽑는다. 나라별 전압·플러그까지 본다.
- 여행 기간에 찍은 **기기 사진**을 모아 보여 주고, 영수증 사진을 지출에 붙인다.
  키를 넣어 두면 영수증 사진에서 **금액과 가맹점을 읽어** 채운다(누를 때만 보낸다).
- **현금 지갑**: 환전·인출한 돈에서 현금 지출을 빼 지금 주머니에 남은 돈과 실제로 산 환율을 본다.
- **문서 보관함**: 여권·보험증서·바우처를 기기 안에 두고 데이터 없이 꺼내 본다. 번호는 가려 둔다.
- **홈 화면 위젯**: 오늘 쓸 수 있는 돈과 다음 일정 두 줄.
- 시차가 있으면 **현지 시각과 한국 시각**을 나란히 보여 준다.

**그 밖에**
- 여행 전에 산 것(항공권·캐리어 등)을 **도착 예정일(ETA)과 함께** 기록한다. 주문 문자를
  Volp로 **공유**하거나 글을 **블록으로 잡아 넘기면** 금액·예정일·송장번호를 읽어 채운다.
  출발 전에 못 받을 것 같으면 미리 알려 준다.
- 기록을 **Google Drive의 `볼프` 폴더**에 백업한다(복원용 JSON + 열람용 CSV).
- **다른 안드로이드 기기와 같은 기록을 쓴다**(Firestore). 기록 하나하나를 짝지어 합치므로
  두 폰에서 각자 넣은 것이 사라지지 않는다. → [설정 방법](docs/firebase-setup.md)
- 새 빌드가 올라오면 앱이 알려 주고, 확인을 받아 **직접 내려받아 설치**한다.

## 쓰는 외부 서비스

모두 API 키가 필요 없거나, 사용자의 계정으로만 동작한다.

| 용도 | 서비스 | 키 |
| --- | --- | --- |
| 환율 | open.er-api.com | 필요 없음 |
| 날씨 예보 | Open-Meteo | 필요 없음 |
| 장소 좌표 | 안드로이드 내장 지오코더 | 필요 없음 |
| 길찾기 | Google 지도 앱으로 넘김 | 필요 없음 |
| 백업 | Google Drive (`drive.file` 범위) | 사용자 OAuth |
| 기기 동기화 | Firebase Firestore + 익명 로그인 | `GOOGLE_SERVICES_JSON` 시크릿 |
| 업데이트 | GitHub Releases | 공개 저장소 |

## 두 가지 빌드

한국에서 도는 Google Play 프로텍트의 **향상된 사기 방지**는 스토어 밖에서 설치하는 앱이
문자 읽기·알림 접근·앱 설치 권한을 함께 요구하면 코드를 보지 않고 설치를 막는다. 보이스피싱
앱이 OTP를 가로챌 때 쓰는 조합이기 때문이다. Volp가 카드 문자를 저절로 읽으려면 똑같은 권한이
필요해, 그대로는 "악성 앱으로 의심"이라며 설치되지 않는다.

그래서 빌드를 두 갈래로 낸다.

| | `volp-safe` | `volp-full` |
| --- | --- | --- |
| 설치 | 그냥 된다 | `adb install -r`로만 |
| 카드 결제 | 문자를 **공유**해서 넣는다 | 문자·알림에서 저절로 모은다 |
| 새 버전 | 알림 뒤 브라우저에서 받는다 | 앱이 받아서 바로 설치한다 |
| 그 밖의 기능 | 모두 같다 | 모두 같다 |

서명과 패키지 이름이 같아 서로 덮어써도 **기록은 그대로 이어진다**. 평소에는 `safe`를 쓰고,
카드 문자를 저절로 모으고 싶을 때만 PC를 꺼내 `full`로 갈아타면 된다.

```bash
adb install -r volp-full-1.0.17.apk
```

## 빌드

GitHub Actions(`.github/workflows/android-release.yml`)가 푸시마다 릴리스 APK를 만들어
GitHub 릴리스로 올린다. 태그는 `v<versionName>` 형식이고 마지막 자리가 버전 코드다.

### 필요한 저장소 시크릿

| 이름 | 설명 |
| --- | --- |
| `KEYSTORE_BASE64` | 릴리스 서명 키스토어(.jks)를 base64로 인코딩한 값 |
| `KEYSTORE_PASSWORD` | 키스토어 비밀번호 |
| `KEY_ALIAS` | 키 별칭 |
| `KEY_PASSWORD` | 키 비밀번호 |
| `MAPS_API_KEY` | Maps SDK for Android 키. 없으면 지도 대신 지도 앱 링크가 뜬다 |
| `GOOGLE_SERVICES_JSON` | `google-services.json`을 base64로 인코딩한 값. 없으면 기기 동기화가 꺼진다 |
| `GEMINI_API_KEY` | 영수증 읽기에 쓴다. 없으면 그 버튼이 나오지 않는다 |

시크릿이 없으면 디버그 키로 서명되며, 기존 설치본 위에 업데이트되지 않는다.

### 로컬 빌드

```bash
./gradlew assembleDebug
```

릴리스 키로 로컬에서 빌드하려면 `keystore.properties`에 `storeFile`, `storePassword`,
`keyAlias`, `keyPassword`를 적는다. 이 파일은 저장소에 올리지 않는다.

## 구조

```
domain/      순수 코틀린. 예산 계산, 카드 문자 파서, 집계 로직 (안드로이드 의존성 없음)
data/        Room 저장소, 설정(DataStore), 업데이트 확인
ui/          Compose 화면과 ViewModel
```

`domain`은 안드로이드에 기대지 않으므로 단위 테스트로 전부 검증한다.

```bash
./gradlew testReleaseUnitTest
```
