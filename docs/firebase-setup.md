# 기기끼리 기록 맞추기 (Firestore)

안드로이드 폰 두 대에서 같은 여행 기록을 쓰기 위한 설정이다. 한 번만 해 두면 된다.

## 왜 Firestore인가

Drive 백업은 파일 한 덩어리를 올리고 내리는 것이라, 두 폰이 각자 기록을 넣으면 나중에 올린
쪽이 앞선 기록을 덮는다. Firestore는 **기록 하나가 문서 하나**라 서로 다른 기록을 고쳤으면
둘 다 남는다. 같은 기록을 양쪽에서 고쳤을 때만 나중에 고친 쪽이 남는다.

Drive 백업은 그대로 둔다. 계정이 통째로 날아갔을 때를 대비한 사본이고, CSV는 PC에서 열어 보는 용도다.

## 1. Firebase 프로젝트 만들기

1. <https://console.firebase.google.com> 에서 프로젝트를 만든다.
2. **Android 앱 추가**
   - 패키지 이름: `com.volp.travelbudget`
   - SHA-1: 설정 화면 맨 아래 **서명 지문 (SHA-1)** 에 찍힌 값
3. `google-services.json` 을 내려받는다.

## 2. Firestore와 익명 로그인 켜기

- **Firestore Database** → 데이터베이스 만들기 (프로덕션 모드)
- **Authentication** → 시작하기 → **익명** 공급자 사용 설정

앱은 누구인지 묻지 않는다. 익명 계정은 "앱을 거쳐 들어왔다"를 확인하는 용도이고,
**어느 기록을 보는지는 동기화 코드가 정한다**.

## 3. 보안 규칙

Firestore → 규칙에 아래를 넣는다.

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // 동기화 코드를 아는 기기만 그 자리를 읽고 쓴다.
    // 코드는 32글자 알파벳에서 16자를 무작위로 뽑은 값이라 찍어서 맞힐 수 없다.
    match /spaces/{code}/{document=**} {
      allow read, write: if request.auth != null && code.size() >= 16;
    }
  }
}
```

코드는 비밀번호와 같다. 남에게 보이지 않게 한다.

## 4. 저장소 시크릿 넣기

`google-services.json` 에는 프로젝트 식별자가 들어 있어 공개 저장소에 두지 않는다.
base64로 바꿔 시크릿에 넣으면 CI가 빌드할 때만 되살린다.

```bash
base64 -w 0 google-services.json
```

출력값을 저장소 시크릿 **`GOOGLE_SERVICES_JSON`** 으로 등록한다.

시크릿이 없으면 빌드는 그대로 되고, 기기 동기화만 꺼진 채로 나온다. 앱 설정 화면에서
그 사정을 알려 준다.

## 5. 앱에서 쓰기

1. 첫 번째 폰: 설정 → **다른 기기와 함께 쓰기** → `코드 만들기`
2. 두 번째 폰: 같은 자리에 그 코드를 넣고 `이 코드로 맞추기`

그다음부터는 앱을 열 때와 여섯 시간마다 알아서 맞춘다. `지금 맞추기`로 바로 할 수도 있다.

### 지운 기록은 어떻게 되나

지운 기록은 흔적(tombstone)을 남긴다. 이것이 없으면 다른 폰에 남아 있던 기록이 다음 동기화에서
되살아난다. 흔적도 함께 오가므로 한쪽에서 지우면 양쪽에서 지워진다.
