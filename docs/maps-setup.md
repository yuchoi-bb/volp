# 지도 키 받기 (Maps SDK for Android)

일정 탭의 지도를 보려면 키가 하나 필요하다. 한 번만 하면 된다.

앱이 쓰는 구글 서비스는 **Maps SDK for Android** 하나뿐이다. 장소 이름으로 좌표를 찾는 일은
안드로이드에 들어 있는 지오코더가 하므로 키도 요금도 들지 않는다.

## 1. 프로젝트

https://console.cloud.google.com 에서 프로젝트를 만든다. 드라이브 백업을 위해 만들어 둔
`Volp` 프로젝트가 있으면 그것을 그대로 쓰면 된다.

## 2. Maps SDK for Android 켜기

**API 및 서비스 → 라이브러리** → `Maps SDK for Android` → **사용 설정**

켜는 과정에서 **결제 계정 연결**을 요구한다. 카드가 등록되어야 키가 동작한다.
모바일 지도(Maps SDK for Android)의 지도 표시는 요금이 붙지 않지만, 요금 정책은 구글이
바꾸므로 <https://mapsplatform.google.com/pricing/> 에서 지금 기준을 한 번 확인하는 편이 좋다.
걱정되면 아래 5번의 예산 알림을 걸어 두면 된다.

## 3. 키 만들기

**API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**

## 4. 키에 자물쇠 걸기 (꼭 한다)

키는 APK 안에 들어간다. 제한을 걸지 않으면 남이 꺼내 써도 요금은 내가 낸다.
방금 만든 키의 **키 수정** 화면에서 둘 다 건다.

| 항목 | 값 |
| --- | --- |
| 애플리케이션 제한 | **Android 앱** |
| 패키지 이름 | `com.volp.travelbudget` |
| SHA-1 인증서 지문 | `58:31:1C:62:C3:E2:7D:3C:28:B1:33:A9:6A:72:88:5C:AA:D6:6D:9B` |
| API 제한 | **Maps SDK for Android** 만 선택 |

SHA-1은 GitHub Actions가 APK에 서명할 때 쓰는 릴리스 키스토어의 지문이다. 앱 **설정 화면 맨
아래 '서명 지문 (SHA-1)'** 에도 같은 값이 찍혀 있다. 그 값이 다르면 그 APK는 이 키를 쓰지 못한다.

## 5. 예산 알림 (선택)

**결제 → 예산 및 알림 → 예산 만들기** 에서 한 달 1,000원 같은 작은 금액으로 걸어 두면, 무언가
잘못되어 요금이 붙기 시작할 때 메일이 온다.

## 6. 저장소 시크릿에 넣기

키는 저장소에 두지 않는다. 빌드할 때만 넣는다.

GitHub 저장소 → **Settings → Secrets and variables → Actions → New repository secret**

- 이름: `MAPS_API_KEY`
- 값: 만든 키

시크릿이 없으면 빌드는 그대로 되고 지도만 빈 채로 나온다. 앱 설정 화면 맨 아래에서 지금 빌드에
키가 들어 있는지 알려 준다.

## 7. 확인

다음 빌드를 설치하고 여행 → **전체일정** 탭을 연다. 지도가 뜨고 그날 갈 곳이 찍힌다.

| 증상 | 확인할 것 |
| --- | --- |
| 지도 자리가 비어 있다 | 설정 맨 아래에 '지도 키 없음'이라고 적혀 있는지. 그러면 시크릿을 넣고 다시 빌드한다 |
| 회색 바둑판만 보인다 | 키 제한의 패키지 이름과 SHA-1이 맞는지, API 제한에 Maps SDK for Android가 들어 있는지 |
| `이 API 프로젝트는 지도를 사용할 권한이 없습니다` | 2번에서 Maps SDK for Android를 켰는지, 결제 계정이 연결됐는지 |
