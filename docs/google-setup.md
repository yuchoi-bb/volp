# Google Drive 백업 설정

앱이 내 드라이브의 `볼프` 폴더에 기록을 올리려면 Google Cloud Console에서 OAuth 클라이언트를
한 번 등록해야 한다. 앱 쪽 코드는 이미 준비돼 있고, 아래 설정만 마치면 바로 동작한다.

## 1. 프로젝트 만들기

1. https://console.cloud.google.com 접속
2. 상단 프로젝트 선택 → **새 프로젝트** → 이름 `Volp` → 만들기

## 2. Drive API 켜기

1. 좌측 메뉴 **API 및 서비스 → 라이브러리**
2. `Google Drive API` 검색 → **사용 설정**

## 3. OAuth 동의 화면

1. **API 및 서비스 → OAuth 동의 화면**
2. User Type: **외부** 선택 → 만들기
3. 앱 이름 `볼프`, 사용자 지원 이메일과 개발자 연락처에 본인 이메일 입력
4. 범위(Scope) 추가에서 `.../auth/drive.file` 선택
   - 이 범위는 **앱이 만든 파일에만** 접근한다. 민감/제한 범위가 아니라 Google 검수 없이 쓸 수 있다.
5. 테스트 사용자에 본인 Google 계정 추가
   - 게시 상태를 '테스트'로 두면 등록한 테스트 사용자만 쓸 수 있다. 혼자 쓰는 앱이므로 이대로 두면 된다.

## 4. Android OAuth 클라이언트 등록

**API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**

| 항목 | 값 |
| --- | --- |
| 애플리케이션 유형 | Android |
| 이름 | Volp Android |
| 패키지 이름 | `com.volp.travelbudget` |
| SHA-1 인증서 지문 | `58:31:1C:62:C3:E2:7D:3C:28:B1:33:A9:6A:72:88:5C:AA:D6:6D:9B` |

이 SHA-1은 GitHub Actions가 APK에 서명할 때 쓰는 릴리스 키스토어의 지문이다.
다른 키로 서명한 APK는 이 클라이언트를 쓰지 못한다.

> 안드로이드 OAuth 클라이언트는 앱에 넣을 파일(`google-services.json` 등)이 따로 없다.
> 패키지 이름과 서명 지문으로 앱을 확인하므로 등록만 하면 된다.

## 5. 앱에서 확인

1. 새 APK를 설치하고 **설정 → 백업 → 지금 백업**
2. Google 계정 선택과 드라이브 접근 동의 화면이 뜬다 → 허용
3. 내 드라이브에 `볼프` 폴더가 생기고 그 안에 두 파일이 올라간다
   - `volp-backup.json` — 복원용
   - `volp-expenses.csv` — PC에서 바로 열어 보는 용도

한 번 동의하고 나면 하루에 한 번 자동으로 백업된다.

## 잘 안 될 때

| 증상 | 확인할 것 |
| --- | --- |
| 계정 선택 화면이 바로 닫힌다 | SHA-1 지문과 패키지 이름이 정확한지, 설치한 APK가 릴리스 키로 서명됐는지 |
| `앱이 확인되지 않았습니다` | OAuth 동의 화면의 테스트 사용자에 내 계정이 들어 있는지 |
| 백업은 되는데 폴더가 안 보인다 | 드라이브 검색창에 `볼프` 입력. 내 드라이브 최상위에 생긴다 |
